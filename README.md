# PROMPT-BUILDER

Aplicação React para montar briefings técnicos e prompts de sistema.

## Rodar localmente

```powershell
npm install
npm run build
npm run standalone
```

Depois abra `http://localhost:5173`.

Para desenvolvimento:

```powershell
npm run dev
```

## Publicação

O projeto inclui um workflow de GitHub Pages em `.github/workflows/deploy.yml`.

Veja o passo a passo em `docs/github-pages.md`.
